# Husnain Nadeem — Cloud & DevOps Portfolio

A static professional portfolio designed to showcase my Computer Science, Cloud, DevOps, AWS, Kubernetes, CI/CD and IoT journey.

## Included
- Interactive project cards with verified GitHub and LinkedIn evidence links
- HCCDP – Solution Architectures / Cloud Developer Professional training section
- Jenkins, ArgoCD, AWS, CloudFormation, Terraform, Kubernetes, EKS, Docker and IoT portfolio content
- Resume and detailed CV PDFs
- Contact links for email, LinkedIn and GitHub

The portfolio itself will therefore become part of the DevOps project demonstrated on the website.
